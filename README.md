# cafe-landing

동네 카페를 소개하는 **한 장짜리 랜딩 페이지**예요. 연습용으로 만든 정적 웹사이트이며, 카페 이름·메뉴·주소·전화번호는 모두 임시 문구입니다.

🔗 **사이트 보기**: https://aanzzi.github.io/cafe-landing/

## 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 페이지 내용 (히어로, 대표 메뉴, 소개, 오시는 길, 푸터) |
| `style.css` | 디자인과 반응형 레이아웃 |
| `README.md` | 이 폴더에 대한 설명 |

## 실행 방법

별도 설치나 빌드가 필요 없어요. `index.html`을 브라우저로 열면 됩니다.

## 배포

GitHub Pages로 `main` 브랜치의 루트 폴더를 배포하고 있어요. `main`에 푸시하면 사이트에 자동 반영됩니다.

## 수정하기

- 카페 이름, 메뉴, 주소, 전화번호는 `index.html`에서 바꿔요.
- 색상과 글꼴은 `style.css`에서 바꿔요.
